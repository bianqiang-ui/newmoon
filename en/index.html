Capabilities

A Markdown editor, honed into a fine tool

From first keystroke to final draft: writing, organizing, computing, presenting, exporting — five stages, each polished.

Writing

What you type is what you see

Real-time rendering on Tiptap / ProseMirror: type Markdown syntax and the characters turn into formatting on the spot. Flip back to source mode anytime — plain text is always your safety net.

  • Headings, lists, quotes, task lists, tables, code blocks, highlight, sub & superscript
  • Smart punctuation and CJK typographic detail — every line reads publication-ready
  • Autosave plus conflict alerts: lose power, not your draft

Organizing

Bidirectional links & a knowledge graph

One folder is one vault. [[Wikilinks]] weave your notes into a web: a backlinks panel, hover previews and a force-directed graph — knowledge stops being a scatter of islands.

  • Full-vault search, file tree, recent-vault session restore
  • Backlinks and unlinked mentions: every sentence keeps its trail
  • Graph view: nodes are notes, edges are links
Knowledge graphClick to enlarge
Computing

Diagrams and formulas, built in

mermaid flowcharts, sequence and Gantt diagrams plus KaTeX math render natively — double-click to zoom in. Pipe syntax typed straight into tables keeps data wrangling inside the editor.

  • mermaid renders offline; exports carry the diagrams too
  • KaTeX inline / block math, embedded fonts, fully offline
  • Footnotes, table of contents, task lists — the skeleton of a long document, built in one pass
Diagram zoomClick to enlarge
Encoding

Encoding-aware, CJK-friendly

Detects UTF-8 / GBK / GB18030 / Big5 / Shift-JIS and other common encodings automatically, then writes back losslessly in the original one. Line endings, BOMs and stray bytes are all handled — mix legacy systems, old documents and AI toolchains freely, and nothing ever garbles.

  • The status bar shows the current file's encoding and line-ending style, live
  • One-click convert and save-as: open legacy archives with confidence
Dark themeClick to enlarge
Publishing

One draft, published everywhere

Export to HTML / PDF / images / print with WYSIWYG pagination and layout. Pasted images land automatically inside the vault, so documents move without broken links. Clip the web and good articles arrive as notes.

  • PDF / print: tables split row by row, long documents paginate cleanly
  • HTML exports read offline — formulas and diagrams travel with the document
  • Browser clipper extension (experimental): one click turns a web page into a .md note
